# 저장소 게시 파일과 제외 규칙

게시 대상은 [PUBLISH_FILES.txt](../PUBLISH_FILES.txt)에 나열한 소스·테스트·설치 스크립트·예제·현재 문서입니다. 실제 파일을 검토한 명시적인 목록이며 폴더 전체 업로드 목록이 아닙니다. `.gitignore`는 루트 파일을 기본 제외하고 필요한 항목만 허용합니다.

## 포함하는 자료

- TypeScript·Swift 소스, 메뉴바 앱의 프로젝트 제작 아이콘 원본과 로컬 회귀 테스트.
- 설정·시작·진단 스크립트의 코드; 실행 결과는 제외합니다.
- `package.json`, `package-lock.json`, `tsconfig.json`.
- 가상 ID·경로만 넣은 설정 예제와 Slack 앱 매니페스트.
- README, 개인정보·원시 운영 기록을 제외한 프로젝트 개요서, 설치·플랫폼 설정·운영·현재 Aside 연결 문서.

별도의 배포 라이선스는 지정하지 않았습니다. 저장소를 만든다는 이유로 임의의 오픈소스 라이선스를 추가하지 않습니다.

## 제외하고 원본을 보존하는 자료

| 범위 | 제외 이유 |
|---|---|
| 로컬 설정·`.env*` | 실제 ID·기기 경로·환경값 |
| `.data/**`, DB·WAL·SHM·로그·잠금·진단·recovery·attachments | 대화·개인 파일·운영·복구 결과 |
| 레지스트리·키·인증서·임시 토큰 | 세션 소유권 자료와 자격증명 |
| 과거 `docs/20*.md`, `docs/superpowers/**`, `.local-notes/**` | 개인 환경 작업 이력·문서 원본 |
| `node_modules`, `dist`, `.tools`, 네이티브·벤더 바이너리 | 의존성·빌드 출력·벤더 자료 |
| 계정 프로필·회사 자료·스크린샷·원시 세션 | 소스 관리 범위 밖 |

제외 자료를 삭제해서 게시하지 않습니다. 실제 설정은 해당 Mac과 Keychain에서 관리합니다. 문서의 토큰 접두어, 테스트의 가상 ID·잘못된 URL·합성 토큰은 실제 자격증명이 아닙니다.

## 게시 전 확인

```sh
npm run typecheck
# 실행 중인 프로젝트에서는 dist를 덮어쓰지 않습니다.
# 테스트·앱 빌드는 docs/setup.md의 격리 작업 사본 절차를 따릅니다.
git add --pathspec-from-file=PUBLISH_FILES.txt
git diff --cached --name-only
git diff --cached --check
```

`git add .`나 폴더 전체 업로드 대신 허용목록을 사용합니다. staged 목록이 허용목록의 부분집합이고 커밋 전체 파일 목록이 허용목록과 같은지, 설정·DB·로그·복구·바이너리가 없는지 확인합니다. 본문은 토큰·개인 키·실제 개인/회사 ID·이메일·기기 경로를 검사하며 발견한 비밀값은 그대로 출력하지 않습니다.

2026-10-02 확인한 현재 저장소는 공개 상태입니다. 게시 전 대상 저장소와 공개 범위를 다시 확인하며 공개 여부를 임의로 변경하지 않습니다. 기존 동명 저장소를 덮어쓰거나 force push하지 않습니다. 게시 후 공개 범위가 유지되고 원격 커밋과 전체 파일 목록이 검토한 로컬 내용과 같은지 확인합니다. Git 작업을 위해 봇을 재시작할 필요는 없습니다.
